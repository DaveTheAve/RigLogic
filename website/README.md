# RigLogic website

This folder is the deployable static RigLogic marketing site.

For the current pre-release phase, `index.html` is deliberately self-contained: its CSS, JavaScript, logo, and illustrated example images are embedded in the document. That keeps the GitHub Pages deployment simple and prevents the public repository from accumulating private application source or build artifacts.

## Editing during pre-release

- Marketing copy, links, and labels can be edited directly in `index.html`.
- The page is currently marked `noindex,nofollow` while copy and screenshots are still being polished.
- The gallery uses neutral **interface illustrations**, not a personal profile and not claims of fresh native screenshots.
- The public download is intentionally shown as coming soon until a real GitHub Release exists.
- Before public launch, replace the illustrated examples with reviewed native RigLogic screenshots if desired, update the release link/version, and remove the preview indexing restrictions.

The Pages workflow publishes **only this directory**.
