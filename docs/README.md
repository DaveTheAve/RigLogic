# RigLogic public documentation

Public user documentation will live here as RigLogic approaches its first release.

Planned sections include:

- Getting started
- Devices and device reassociation
- Mapping controls and behaviors
- Calibration, deadzones, inversion, and filtering
- Recorded-input / Filter Lab workflows
- Virtual-controller output and binding
- Monitor overlays
- Troubleshooting and diagnostics
- Game/application compatibility notes
- Updating RigLogic

The application source and private development infrastructure are intentionally not part of this public repository.
